## 三种东西常被混为一谈

“我需要一个 ChatGPT 账号”这句话，至少要拆成三种完全不同的东西：

- **订阅**：按月付费的个人会员。ChatGPT Plus、Claude Pro、Gemini 的高级版都属于这一类。
- **API Key**：一串字符串，按 token 计费，给程序调用。
- **转手订阅 / 成品号**：别人已经开好的订阅，把使用权交付给你。

它们在技术上都“能用 AI”，但账单、额度、能不能接管、出问题找谁，全是两码事。选错不会当场报错——错误会在月底账单、某次 `429`，或者某天登录不上去的时候才出现。

## 一张表看清区别

| | 个人订阅 | API Key | 转手订阅 |
| --- | --- | --- | --- |
| 计费方式 | 按月固定 | 按 token 用量 | 一次性或按月付给中间商 |
| 额度怎么表达 | 窗口内可用次数 | 账户余额 / 用量上限 | 名义上是“无限”，实际受原账号限制 |
| 能否登录官方 App | 能 | **不能** | 能，但设备数受限 |
| 能否给 Codex CLI / Claude Code 用 | 能 | 能 | 能，但会被设备与并发限制卡住 |
| 用完之后 | 等窗口重置 | 余额扣完即停 | 找卖家，或直接失效 |
| 账号控制权 | 你的 | 你的 | **对方的** |
| 适合谁 | 自己天天用 | 写程序、跑自动化 | 短期、可替换、金额可承受 |

第三列写“对方的”不是修辞。密码、二次验证、绑定邮箱、支付方式都在原持有人手上，你拿到的是一个使用权，不是所有权。

## 三个自检问题

**一、你要的是“我自己在网页或终端里用”，还是“我的程序去调用”？**

前者要订阅，后者要 API Key。两个都要，就两份钱都要花——API 的费用不会因为你有订阅而减少。

**二、你的用量是“每天几十条对话”，还是“每天几十万 token”？**

按次计的订阅适合人；按量计的 API 适合机器。让机器去消耗订阅额度，通常比直接付费更贵，因为并发一上来就撞窗口。

**三、出问题时，你能不能自己改密码、看账单、提工单？**

能，就在订阅和 API 之间选；不能，先接受“这不是资产，是租用”这个前提，再决定值不值。

## 订阅在各家 CLI 里到底管不管用

这是最容易踩空的一格，逐个说清：

- **Codex CLI**：可以用 ChatGPT 账号登录，消耗订阅额度；也可以改用 API Key。两种登录方式对应两套计费。
- **Claude Code**：用 Claude 订阅（Pro / Max）登录时消耗订阅额度；用 Anthropic API Key 时按量计费。
- **Gemini CLI**：可以用 Google 账号的免费额度起步，也可以换成 API Key。

所以“我有 Plus 了，为什么 Claude Code 还要钱”这类困惑，本质是把两家的订阅当成了同一个东西。它们互不相通。

## 转手订阅的真实代价

不该只讲“便宜”，该讲清楚便宜买走的是什么：

- **会话会被踢**：同一账号多端登录，平台的风控和会话策略会相互挤掉。
- **设备数上限**：Pro 类订阅对同时登录的设备数量有约束，人多时轮流掉线。
- **改密码即失联**：原持有人随时可以重置，重置之后你什么也做不了。
- **风控命中即封停**：账号共享在多数平台条款里都是禁止项，命中后没有申诉通道，也没有补偿。
- **二次验证绑在别人手机上**：需要验证码的那一步，你永远是被动的一方。

结论不复杂：**把它当租用，不当资产**。短期验证想法、跑一次演示、金额可承受，可以；当生产环境的主账号，不行。

## 用一次只读请求确认手里是什么

不用猜，两条命令就能看出当前凭据属于哪一类：

```bash
# Codex CLI：看登录方式与当前账号
codex login status

# Claude Code：进入交互界面后查看账号与模型
claude
# 然后在会话里输入
/status
```

`codex login status` 输出里区分 `chatgpt` 与 `api_key` 两种登录来源；`/status` 会显示当前账号类型、模型与额度窗口。看到哪一种，就知道这次请求的钱从哪里出。
