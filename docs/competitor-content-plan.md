## 写作与核验标准

- 每篇回答一个具体问题，有前置条件、完整步骤、可观察的结果、失败排查、验收和延伸阅读。
- 竞品只用于发现需求；命令、配置和产品行为只依据官方文档。官方页面抓取记录见 `.work/content-research/manifest*.json`。
- 新文末注明官方来源与核对日期；明确区分“文档核对”“本地示例执行”和“需要用户账号的端到端验证”。不把生成的示例输出写成实测结果。
- 不安装客户端、不调用付费模型、不修改用户登录、密钥或 DNS。可独立执行的示例优先用已有 Node.js 和 Git 在临时目录核验。
- 不为凑篇数添加工具排名、未经验证的性能对比、价格或泛泛提示词列表。
- 新内容必须出现在分类、路线、站内搜索、RSS 与 sitemap 中；测试从源文件清单读取预期文章，不能只检验固定的旧 12 篇。
