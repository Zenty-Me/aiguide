# Zenty AI Guide 视觉重做计划

日期：2026-11-14  
范围：现有 Astro + TypeScript + Tailwind 站点，保留 12 篇教程正文、内容 schema、路由 ID、SEO 域名与已验证功能。

## 1. 目标与边界

用户原话：「现在的页面一股ai味，不高级简洁明了，你用design-taste-frontend再优化一遍」。

> 归属说明：除上面这一句外，本文记录的具体取舍——配色 token、字号阶梯、禁用照片／伪 UI／动效场景、自然高度、页脚形态等——来自派发任务的说明与本方案的推导，不是用户的逐字要求，按「实施方案决策」记录。用户的原话只有上面这一句，其余表述都是本条诉求的展开或本方案的取舍。

本次不是做营销落地页，而是把教程知识库做成一个可信、耐读、找内容快的编辑部式网站。明确的优先级：

1. 教程与路线必须第一眼可读、可点，首页不是产品宣言。
2. 接近白的中性纸面、深中性墨色、单一克制的松绿色强调色；深浅主题同一套层级。
3. 中文正文稳定使用 sans，字号和行高舒适；不出现宋体回退、不出现 12px 小字堆叠。
4. 自然内容高度、整齐基线，不为了“一屏一区块”制造长空白、巨型字体或装饰场景。
5. 不使用照片、伪终端、伪仪表盘、shader/WebGL、暗色荧光风、重复圆角边框卡片。
6. 保留搜索失败重试、主题持久化、移动导航、目录、阅读进度、代码复制、相关文章、prev/next、RSS/sitemap/metadata。

技能：实际加载并应用 `design-taste-frontend`（SKILL.md、`copy.md`、`copy-voice.md`、`system.md`、`layout-v4.md`、`sections.md`、`references/gate.md`、`references/perf.md`），未使用 frontend-design 替代。技能是设计约束与检查器，不覆盖任务说明与用户「简洁明了」所指向的自然高度、不堆装饰；不适用项在 `.taste-skill/waivers.json` 与验证报告中逐条说明。

## 2. 旧版问题诊断

- 冷蓝全站底色与点阵英雄背景，让内容站像模板 SaaS。
- 细边框圆角卡片重复出现，三列营销卡矩阵造成机械节奏。
- 四套虚线学习路线重复表达同一种“路线”概念，图层噪音大。
- 过量全大写英文 marker、空洞口号和“如何用指南”填充段，信息密度低。
- 首页过长（1440 宽约 3592px），首屏被品牌宣言占据，真实教程入口不够直接。
- 中文正文存在字体不统一/疑似宋体回退，部分 12px 标签对比度不足。
- 深浅主题与语义层级不够统一，暗色像简单反相。

## 3. 设计方向：编辑部阅读室

一句话：**纸面、墨色、一条松绿色的阅读线索**。  
关键词：安静、清楚、有编辑判断、可快速扫读；不是“AI 产品官网”。

### 3.1 色彩

浅色（默认）：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#faf9f6` | 页面底色，暖近白 |
| `--surface` | `#f2f0ea` | 主题索引带、次级面 |
| `--ink` | `#1b1a16` | 标题与正文主墨色 |
| `--ink-soft` | `#3d3a33` | 次级正文 |
| `--muted` | `#6b665b` | meta、说明；仍满足小字对比度 |
| `--line` | `rgba(27,26,22,.13)` | 发丝分隔线 |
| `--accent` | `#235c4b` | 松绿色，链接/强调 |
| `--accent-strong` | `#1b4a3c` | hover 与高对比文字 |
| `--accent-soft` | `#e2ece6` | tonal 主按钮底色 |
| `--footer` | `#171612` | 深色页脚 |

深色使用独立 token，不做反相：`paper #14130f`、`ink #f3f0e7`、`accent #9bcbb6`、`footer #0e0d0a`。全站没有渐变、荧光、发光阴影或半透明毛玻璃。

### 3.2 字体与字号

- 拉丁与数字：自托管 Host Grotesk（400–600，`public/fonts/host-grotesk-latin.woff2`）。
- 中文：`PingFang SC`、`Hiragino Sans GB`、`Microsoft YaHei`、`Noto Sans SC`、`Source Han Sans SC`，最后 `sans-serif`；不把中文交给衬线回退。
- 等宽只用于代码、日期与少量拉丁数字：JetBrains Mono；中文 fallback 仍是 YaHei/sans。
- 正文 `1.0625rem / 1.85`（17px / 31.45px）；文章正文 `17px / 30.6px`。
- `h1.display`：`clamp(2.375rem, 1.5rem + 4.2vw, 3.75rem)`，即 38–60px；不再用 72px 以上的巨型标题。
- 页面标题 36–52px；章节 H2 28–40px；文章正文 H2 约 29.44px。
- 标签与 meta 统一 13px，不再使用 12px 小字；正文和按钮继承 17px。
- 所有排版使用同一套基线节奏：段落、列表、标题的上下间距来自 `--sp-*`。

### 3.3 版式与构图

- `.shell` 最大 80rem，左右 gutter 24/32/48/80px；固定 header 64/72px。
- 首页 hero 是 12 栏：左 7 栏放标题、副标题、入口和真实统计；右 5 栏直接放“最近更新”教程列表。右栏起点与 841px 网格线对齐。
- 只用发丝分隔线组织列表，不做重复边框卡片；分隔线在列表行上，不在每个内容块外再套壳。
- 章节标题左对齐，说明在标题下方，相关入口在右端；不使用居中大标题和对称三列卡。
- 首页顺序：Hero（标题 + 一句副标题 + 第一条教程 + 阅读路线 + 真实统计 + 最近更新）→ 三条路线，按顺序读（三行有层级的路线入口，每行 4 个真实步骤）→ 按工具和问题浏览（6 个主题，轻量索引）→ 页脚。
- 删除重复产品宣言、“阅读方式”填充段、重复的“最新教程”矩阵、无信息增量的技术实现介绍。
- 页面高度：1440 宽从约 3592px 降到 2712px；390 宽 4351px；仍保留全部 12 篇教程、3 条路线和 6 个主题的入口。

### 3.4 页面级设计

- **教程列表**：页头 + 最近 5 条 + 按主题分组的发丝行；每行是分类/难度、标题、摘要、日期，不套卡。
- **分类索引**：2 栏分类条目，每类直接列出前 4 篇教程和“查看 N 篇”，让主题页本身可阅读。
- **学习路线**：每条路线一个 section，标题、摘要、统计、4 个步骤；步骤是文字链接与难度标签，不用虚线轨道和节点装饰。
- **搜索**：搜索框与筛选项保持真实可用；结果行用标题、分类、摘要；保留空结果、失败、重试、URL 参数、快捷键。
- **文章**：阅读进度条、面包屑、分类/难度/时长、大标题、摘要、发布/更新与标签、正文、所属路线、prev/next、相关教程、桌面 sticky 目录、移动端折叠目录。正文区域保持单栏舒适行宽。
- **关于/更新/404**：同样使用页头 + 正文/列表的编辑结构；404 提供回教程和搜索两个明确动作。
- **页脚**：深浅主题都保持深墨色，作为全站收束；包含品牌、订阅、浏览与本站链接、版权与内容声明。没有巨型 wordmark。

### 3.5 交互与可访问性

- 主题按钮切换 `data-theme`，写入 `localStorage['zenty-theme']`，首屏内联脚本避免闪烁；`meta[name=theme-color]` 同步。
- 移动导航按钮、搜索 `/` 快捷键、搜索防抖与中止、失败重试、代码复制状态、阅读进度、目录锚点全部保留。
- 焦点可见（2px 松绿色 outline），skip link，语义化 header/nav/main/footer，`aria-current`、`aria-expanded`、`aria-live` 保留。
- 所有可点击文字在移动端至少 44px 高；正文链接与按钮 hover 有下划线/位移反馈。
- `prefers-reduced-motion` 下关闭 hero 入场与所有过渡；入场只做一次轻微透明度/位移，不做滚动动画。
- 目标对比度：正文 ≥ 4.5:1，大字 ≥ 3:1；实测最低 5.01（浅色首页）、6.95（深色首页）。

### 3.6 明确的技能偏离与理由

这些不是遗漏，而是与「简洁明了、自然高度」这一约束冲突时的取舍；gate 中只对可机读的冲突项登记 waiver，其余在验证报告说明：

| 技能期待 | 本站做法 | 理由 |
| --- | --- | --- |
| 深色或高对比的 dealt palette | 暖近白纸面 + 深墨 + 松绿 | 任务说明要求接近白的中性背景与克制强调色；教程站长读不适合暗色荧光 |
| 每屏一个 section、hero 满屏 | 自然高度；hero 约 680px 后直接进入路线 | 任务说明反对为“一屏一区块”制造长空白 |
| 照片、产品渲染、伪终端/仪表盘 | 真实教程标题、真实分类与计数 | 教程知识库的证据是内容本身；派发说明点名不要伪终端、伪仪表盘与照片，本文据此取舍 |
| 一个 dealt moment/滚动场景 | 只有一次安静的 hero 入场 | 派发说明不鼓励动效场景；阅读页不应抢注意力，本文据此取舍 |
| 尾屏 CTA 按钮 | 主题索引的轻量文字入口 | 不让索引变成销售页；每个主题行本身可点 |
| `.wrap`/kit 容器类、`header.nav` | `.shell`/语义化 header | 现有 Astro 组件的既有约定；视觉与对齐已实测 |
| 页脚品牌与容器同边 | 品牌 mark 相对文字左移 22px | 四点 logo 的视觉重心补偿；文字与页脚正文仍对齐 |
| 全大写英文 marker | 中文 sentence case 标签 | 旧版诊断结论：过量全大写 marker 是模板感来源 |

## 4. 实施范围

- `src/layouts/BaseLayout.astro`：head/SEO/主题初始化/跳过链接/Header/Footer。
- `src/components/`：Header、Footer、ArticleRow、Breadcrumbs、TableOfContents（保留 ThemeToggle/PathRail/RailStep 兼容）。
- `src/pages/`：首页、教程列表、分类索引/详情、路线、搜索、关于、更新日志、404、文章详情。
- `src/styles/global.css`：token、字体、排版、组件与响应式；Tailwind v4。
- `src/scripts/`：搜索渲染类名、主题 meta 同步；搜索/主题/导航/复制/进度逻辑不改。
- `public/`：字体、favicon、og-default；不引入图片库或运行时依赖。
- `.gitignore`：忽略 `.work/`、`.taste-skill/` 等本地产物。
- 测试只适配新的语义选择器：首页 `.path-list`、e2e `.path-list a`、目录 `.toc-wrap a`；功能断言未删减。

不修改：12 篇教程正文、content schema、路由 ID、SEO 域名、已验证教程回归脚本。

## 5. 验收计划

- 视口：1440、1024、768、390、320；桌面首屏、完整首页、深色首页、文章、移动列表、搜索、路线、分类、关于、更新。
- 自动：`npm run check`、`npm run build`、`npm test`（smoke + Playwright e2e）。
- 视觉：技能 `shoot.mjs` 截图 + 技能 `gate.mjs`；自身 `.work/shoot-pages.mjs` 全页截图；人工查看关键图。
- 字体/对比度：浏览器计算样式审计；确认所有采样选择器都解析到 sans 栈，正文 17px。
- 性能：技能 `perf.mjs` 在 1440/390 CPU Chrome 下 PASS；无图片负载、无 WebGL、CLS 0。
- 记录：`docs/redesign-verification.md` 保存真实命令、结果、GATE 行、waiver 与剩余限制。
